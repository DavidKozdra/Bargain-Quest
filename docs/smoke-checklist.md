- [ ] Start new game from menu

## Events and Minigames

- [ ] Launch minigame and complete/forfeit paths

## Save/Load
- [ ] Save game manually
- [ ] Load game and verify player/cities/day-night state restored

## UI and Tutorial
- [ ] Main HUD and info tabs render correctly
- [ ] High score/history tab details populate

## Mobile
- [ ] Touch controls respond
- [ ] Pinch/zoom limits respected
- [ ] Mobile HUD actions usable
